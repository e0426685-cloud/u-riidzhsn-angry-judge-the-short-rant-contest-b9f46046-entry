# Angry Judge: The Short Rant Contest

A short, funny rant about an everyday annoyance: the hotel shower that
has exactly two settings — arctic blast and molten lava — with a knob in
between that is purely decorative.

`main.py` (Python standard library only) writes the rant to
`/output/entry.txt` (1–400 UTF-8 characters, mode 0644 so the grader can
read it) and validates it first with `validate()`.

Run it with:

```sh
python3 main.py
```
